## MacFanControl v1.1.2

本版本修复区域截图方向错误，并统一本地构建与正式发布的 Developer ID 签名流程。

### 截图修复

- 修复保存或复制截图时图片沿水平轴翻转的问题。
- 修复马赛克区域与原图方向不一致的问题。
- 增加非对称像素回归测试，覆盖普通截图和马赛克输出方向。

### 构建与风扇控制服务

- `build-app.sh` 现在自动选择钥匙串中的 `Developer ID Application` 证书。
- 本地应用包改为包含当前的安全 Swift Helper 和 LaunchDaemon 配置。
- 阻止缺少 Team ID 的临时签名包继续生成，避免风扇控制服务无法注册或连接。

### 安装

1. 下载并解压 `MacFanControl_v1.1.2.zip`。
2. 将 `MacFanControl.app` 移入 `/Applications`。
3. 首次运行时根据提示启用风扇控制服务，并在系统设置中批准后台项目。

要求 macOS 13.0 或更高版本。本发布包使用 Developer ID 签名、通过 Apple 公证并装订公证票据。
